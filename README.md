# Motor Control FOC

FOC (Field-Oriented Control) 电机控制算法学习与实现。

## 项目结构

- `PID/`：PID 控制器的 C++ 实现（位置式、增量式、积分限幅、微分先行）
- `Current_Limit/`：电流限幅保护的 C++ 实现

## 技术栈

- C++ / C
- MATLAB / Simulink
- CMake

## 已实现

- [x] PID 控制器（含积分限幅、输出限幅）
- [x] 电流限幅保护
- [ ] Clarke 变换
- [ ] Park 变换
- [ ] SVPWM
- [ ] FOC 闭环
